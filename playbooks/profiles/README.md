# Project Profiles

Profiles extend the Software Delivery Core with requirements specific to a product shape or risk boundary. Select all that apply and record the choice in the project brief.

- [Web application](web-application.md)
- [API service](api-service.md)
- [Mobile application](mobile-application.md)
- [Data and automation](data-and-automation.md)
- [AI-enabled application](ai-enabled-application.md)
- [Agentic AI system](agentic-ai-system.md)
- [Omnichannel agent](omnichannel-agent.md)

Profiles define outcomes and controls, not mandatory vendors. A documented preference such as MUI may be replaced when a clear project-specific technical advantage and its tradeoffs are recorded.
