# Mobile Application Profile

**Status:** Stable
**Version:** 1.0.0

Use with the Software Delivery Core for native or cross-platform mobile products.

## Required decisions

- supported platforms and OS versions;
- navigation, lifecycle, offline behavior, synchronization, and conflict resolution;
- local storage, device permissions, authentication, and sensitive-data protection;
- accessibility, localization, network and battery budgets;
- staged distribution, compatibility, telemetry, and rollback strategy.

## Minimum verification

- tests on supported screen sizes and OS versions;
- offline, poor-network, interrupted-session, and resume behavior;
- permission denial and revoked-access paths;
- secure local storage and log redaction;
- upgrade and backward-compatible API behavior.
