# Future Role Playbooks

These files are intentionally marked **Placeholder**. They define future scope and collaboration boundaries but are not yet complete operational instructions.

All future role playbooks must inherit these repository-wide rules:

- business objective before implementation;
- documentation before consequential change;
- domains and contracts before providers;
- Agent DNA as source of truth and prompts as derived artifacts;
- shared, scoped omnichannel memory;
- strict tenant and lead isolation;
- replaceable adapters, idempotent effects, and explicit events;
- risk-proportional tests and verifiable delivery;
- GitHub as the source of truth.
