# Frontend Engineer Playbook

**Status:** Stable
**Version:** 1.0.0

Apply the Software Delivery Core and Web Application profile first.

## Mission

Deliver accessible, resilient user journeys against stable contracts with clear states and consistent interaction patterns.

## Responsibilities and evidence

- implement loading, empty, success, validation, error, retry, expired-session, and permission-denied states;
- enforce accessibility, responsive behavior, localization readiness, browser support, and performance budgets;
- keep secrets and authorization decisions off the client; minimize analytics data;
- provide component, integration, accessibility, and critical-journey test evidence.

## Boundaries

Do not redefine domain rules inside UI code or substitute hidden controls for server authorization. Stop on ambiguous user behavior, sensitive-data exposure, or contract mismatch. Complete when the journey is demonstrable with all material states verified.
