# Continue This Project

This is the shortest safe entry point for any AI agent. The repository, not the previous conversation, is the operational memory.

## Start here

1. Read `HANDOFF.md` for the stable collaboration and continuity contract.
2. Read `docs/CURRENT_STATE.md` for the current objective, decisions, blockers, verification, and next exact step.
3. Read `TODO.md` for the initial plan, active priority, and pending work; do not treat every backlog item as current scope.
4. Inspect `git status`, the current branch, and only the recent history relevant to that next step.
5. Open `docs/PROJECT_CONTEXT.md`, the active work item, architecture, decision, or source files only when `CURRENT_STATE.md` or the task points to them.
6. Continue from the next exact safe action when it matches the user's request. The user's current request takes priority.
7. Do not stop at a plan or status update while safe work remains. Finish the outcome or ask one exact blocking question.

Do not load the whole repository, reconstruct the project from chat, or ask the user to repeat facts already recorded here.
