# Changelog

All notable changes to stable playbooks and standards are recorded here.

## [Unreleased]

### Added

- Software Delivery Core for all software projects.
- Seven project profiles covering web, API, mobile, data/automation, AI-enabled, agentic, and omnichannel systems.
- Guided getting-started path and plain-language glossary for non-programmers.
- Testing, secure development, AI evaluation, observability, supply-chain, and release standards.
- Operational templates for briefs, work items, risk, threats, AI systems, evaluations, releases, runbooks, and incidents.
- Stable responsibility playbooks for the eleven existing roles.
- Worked examples, executable documentation validation, and a GitHub Actions workflow template.

### Changed

- Software Architect Playbook 2.1 establishes proactive operational leadership, protective care, autonomy by default, and explicit finished-or-blocked interaction endings.
- Software Architect Playbook 2.0 now builds on the universal core.
- Omnichannel-specific guidance moved into a dedicated profile.
- Material UI is the documented default for web dashboards with an explicit exception rule.
- Documentation Standard 2.0 includes operational, risk, and AI artifacts.
